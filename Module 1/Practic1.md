# 1. Цель работы

Изучить и сравнить
популярные инструменты для построения Data Pipeline, понять их архитектуру, преимущества и
недостатки, а также области применения.

## Задачи:

·
Познакомиться
с основными инструментами оркестрации Data Pipeline

·
Провести
сравнительный анализ по ключевым критериям

·
Выработать
рекомендации по выбору инструмента для конкретных задач

·
Получить
практический опыт работы с документацией

## Продолжительность:

45 минут
