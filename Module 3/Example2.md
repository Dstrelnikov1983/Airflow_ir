## 🔍 Детальное объяснение

### **1. Apache Hadoop Core (основные компоненты):**

```
Apache Hadoop состоит из 4-х компонентов:

┌──────────────────────────────────┐
│      Hadoop Common               │  ← Общие библиотеки
├──────────────────────────────────┤
│      HDFS                        │  ← Хранение данных
├──────────────────────────────────┤
│      YARN                        │  ← Управление ресурсами
├──────────────────────────────────┤
│      MapReduce                   │  ← Обработка данных
└──────────────────────────────────┘

Это и есть "Hadoop" в узком смысле
```

**Spark НЕ входит в эти 4 компонента!**

---

### **2. Hadoop Ecosystem (экосистема Hadoop):**

```
Широкое понятие - все технологии Big Data:

┌─────────────────────────────────────┐
│        Hadoop Ecosystem             │
├─────────────────────────────────────┤
│  Обработка:                         │
│  • MapReduce (часть Hadoop)         │
│  • Spark (независимый проект) ⭐    │
│  • Flink (независимый проект)       │
│  • Tez (часть Hadoop)               │
├─────────────────────────────────────┤
│  Хранение:                          │
│  • HDFS (часть Hadoop)              │
│  • HBase (отдельный проект)         │
│  • Kudu (отдельный проект)          │
├─────────────────────────────────────┤
│  SQL интерфейсы:                    │
│  • Hive (отдельный проект)          │
│  • Impala (отдельный проект)        │
│  • Presto (отдельный проект)        │
├─────────────────────────────────────┤
│  Координация:                       │
│  • ZooKeeper (отдельный проект)     │
├─────────────────────────────────────┤
│  Потоковая обработка:               │
│  • Kafka (отдельный проект)         │
│  • Storm (отдельный проект)         │
└─────────────────────────────────────┘
```

**Все это — отдельные проекты Apache Software Foundation!**

Spark входит в "Hadoop Ecosystem", но **не в "Apache Hadoop Core"** .

## 🔗 Как Spark связан с Hadoop?

### **Spark ИСПОЛЬЗУЕТ компоненты Hadoop:**

```
┌─────────────────────────────────────┐
│         Apache Spark                 │
│      (движок обработки)              │
└─────────────────────────────────────┘
              ↓ использует
┌─────────────────────────────────────┐
│  1. HDFS - для хранения данных      │
│  2. YARN - для управления ресурсами │
└─────────────────────────────────────┘
```

---

### **1. Spark читает/пишет данные из HDFS**

python

```python
# Spark читает данные из HDFS
df = spark.read.csv("hdfs://namenode:9000/data/sales.csv")

# Обрабатывает в памяти (движок Spark)
result = df.groupBy("product").sum("amount")

# Записывает результат в HDFS
result.write.parquet("hdfs://namenode:9000/output/result.parquet")
```

**Аналогия:**

- HDFS = жёсткий диск
- Spark = процессор
- Процессор работает с данными на диске, но это разные вещи!

---

### **2. Spark запускается на YARN**

**YARN = менеджер ресурсов кластера**

```
┌───────────────────────────────────────────┐
│           YARN Cluster                     │
├───────────────────────────────────────────┤
│                                            │
│  Node 1:  [MapReduce job] [Spark app]    │
│  Node 2:  [Spark app] [Hive query]        │
│  Node 3:  [Spark app] [Spark app]         │
│  Node 4:  [MapReduce job] [Flink job]     │
│                                            │
└───────────────────────────────────────────┘

YARN управляет ресурсами для ВСЕХ приложений
```
